INTRODUCTION                                                     *terminalia*

Terminalia owns persistent terminal identities, context stacks, terminal
buffers, history, and split/float views. Neovim 0.11 or newer is required.

==============================================================================
SETUP                                                   *terminalia-setup*

>lua
    require('terminalia').setup({
        default_view = 'split',
        persist_terminals = true,
    })
<

The default namespace is "default". Terminal records and output history are
stored below stdpath('state') unless their paths are overridden.

==============================================================================
COMMANDS                                             *terminalia-commands*

                                                *:TerminaliaNew*
:TerminaliaNew [name] [namespace] [view]
    Create and open a terminal.

                                                *:TerminaliaOpen*
:TerminaliaOpen {id} [view]
    Reopen a terminal by id.

                                                *:TerminaliaList*
:TerminaliaList [namespace] [cwd-prefix]
    List known terminals.

                                                *:TerminaliaHistory*
:TerminaliaHistory {id}
    Open captured terminal history.

                                                *:TerminaliaOpenUri*
:TerminaliaOpenUri {uri} [view]
    Adopt or reopen a terminalia:// URI.

    The host context is implicit: terminalia://1 identifies a local terminal,
    and terminalia://1/history identifies its history. Custom names use
    ?name=build. Derived context layers use kind:id path components with
    ;label=value and ;meta.key=value parameters for reopening information.
    Parameter values are percent-encoded. Older hierarchical URI names remain
    readable and are renamed to the compact form when their buffers are adopted.

                                                *:TerminaliaExternalOpen*
:TerminaliaExternalOpen [arguments...]
    Open nvim-style file arguments in the host editor.

==============================================================================
API                                                       *terminalia-api*

The root module exposes `setup()` and `api`. Common API functions include
`create()`, `start()`, `send()`, `wait()`, `kill()`, `release()`, `open()`,
`open_history()`, `create_context()`, and `create_child_context()`.

Terminalia discovers optional Continuity, Ministry, and Overseer integration
at runtime. They are not required for standalone terminal use.
